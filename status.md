## Definitions

- **Gate** = the acceptance test that an increment must pass before its
  status moves from `pending` to `done`.
- **Independence** = each increment can be developed in parallel once its
  upstream artifacts exist (see dependency graph in DESIGN §9.2).
- **Failure** = an increment does NOT modify upstream code to make itself
  pass; it writes a blocker note in `docs/blockers/<I-ID>-<short-name>.md`
  instead.
